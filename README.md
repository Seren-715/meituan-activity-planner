# 🗺️ 本地短时活动规划与执行 Agent

> 中国国际大学生创新大赛（2026）· 创意组作品

**一句话说清**：用户说「下午想和朋友出去玩」，系统自动完成需求澄清 → 本地 POI 检索 → 主备方案生成 → 评分对比 → 一键执行的全流程。

---

## 🎯 解决了什么问题

临时起意想出门玩，但面临三个痛点：
- **决策成本高**：不知道去哪、吃什么、路线怎么安排
- **信息碎片化**：地图、点评、攻略分散在不同 App
- **计划易崩**：排队太久、餐厅满了、天气变了，没有备选方案

本系统将这些流程整合为**一次对话**，自动生成可执行的 4-6 小时活动方案。

## ✨ 核心亮点

| 维度 | 说明 |
|------|------|
| **自然对话** | 一句话输入，多轮 SSE 流式澄清需求（人数、偏好、位置） |
| **双场景** | 内置家庭场景（孩子年龄/饮食清淡）和朋友场景（聊天社交）的结构化理解 |
| **主备对比** | 自动生成 A/B 方案，从距离、评分、价格等多维度打分，展示推荐理由 |
| **异常兜底** | 6 种异常场景模拟（排队/满座/超时/预约失败），自动补偿重试 |
| **Mock 降级** | 无高德 Key 时自动切换内置种子数据，比赛演示永不中断 |
| **需求可视化** | 前端展示结构化标签、规划阶段进度、评分依据拆解 |

## 🚀 5 分钟跑起来

### 前置条件
- Python 3.10+
- Node.js 18+
- 可选：DeepSeek API Key + 高德 Web Service Key

### 启动

```powershell
# 1. 安装后端依赖
pip install -r requirements.txt

# 2. 安装前端依赖
cd frontend && npm install && cd ..

# 3. 配置环境变量（可选，无 Key 自动 Mock）
$env:DEEPSEEK_API_KEY="你的Key"
$env:AMAP_WEB_SERVICE_KEY="你的Key"

# 4. 一键启动
.\start-local.ps1
# 后端 http://127.0.0.1:8002  前端 http://127.0.0.1:4175
```

## 🧪 技术特色

- **LLM 优先 + 规则兜底**：DeepSeek/OpenAI 做语义理解，网络异常时规则保底
- **高德真实数据**：POI 搜索、路线规划、餐饮推荐基于真实 LBS 数据
- **结构化 Goal**：对话阶段直接产出机器可读的结构化目标，减少信息损耗
- **流式交互**：SSE 实时推送，对话即规划
